# Enterprise CRUD Template

This is a complete professional enterprise-level FULL-STACK CRUD application template built with Java (Spring Boot) and React.js.

## Tech Stack
- **Backend**: Java 17, Spring Boot 3, JPA, Hibernate, PostgreSQL, Lombok, Maven.
- **Frontend**: React.js 18, Vite, Axios, React Router, Lucide Icons.
- **Database**: PostgreSQL.

## Features
- Fully functional CRUD operations.
- Professional Dashboard with metrics.
- Reusable UI components (Table, Form, Sidebar).
- Global Exception Handling.
- Business Calculation Engine.
- Pagination & Search.
- Responsive modern design.

## Project Structure
- `/backend`: Spring Boot source code.
- `/frontend`: React.js source code.
- `/database`: SQL scripts for schema and data.
- `/postman`: API test collection.
- `/documentation`: Setup and API guides.
